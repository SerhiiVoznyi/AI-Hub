# Knowledge

Use this folder for stable concepts, glossaries, mental models, and shared contracts that support other artifacts.

Keep this folder focused on durable reference content rather than task-specific instructions. Agents and prompts should **link** these documents instead of restating them.

## Available Knowledge

- [safety-policy.md](./safety-policy.md): operational guardrails (destructive ops, secrets, scope, supply chain, AWS, untrusted input, coding posture) and role enforcement.
- [orchestrated-handoff-protocol.md](./orchestrated-handoff-protocol.md): four-agent topology, allowed loop, and task skills manifest forwarding rules.
- [peer-review-panel-protocol.md](./peer-review-panel-protocol.md): three-agent peer topology, round budget, objection admissibility, chair selection, and consensus rules.
- [agent-return-contracts.md](./agent-return-contracts.md): canonical keyed packages for every orchestrated handoff and peer-panel turn.
- [execution-output-discipline.md](./execution-output-discipline.md): brevity rules for runtime AI execution outputs.
